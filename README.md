# 🎲 Dice Simulator Using Python

## 📌 Project Description
Dice Simulator is a beginner-friendly Python project that simulates rolling a six-sided dice. It generates a random number between 1 and 6, just like a real dice.

## ✨ Features
- Simulates a six-sided dice roll.
- Generates random numbers from 1 to 6.
- Simple and easy-to-understand Python code.
- Beginner-friendly project for practicing Python.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Module:** `random`

## ⚙️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python Dice-simulator.py
```

## 🎯 Learning Objectives
- Understanding Python's `random` module.
- Practicing variables and basic programming logic.
- Building a simple Python project.
